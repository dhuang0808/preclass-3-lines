# 真人计时补录（尚未执行）

目的：补上机器不能代测的“我查资料多久、实际读了几页、三行读完多久”。不把机器抓取网页耗时当作人的阅读时间。

1. 选一个自己尚不熟悉的课前主题，不先看本项目答案。从开始输入搜索词计时，照自己的习惯打开来源；到能口头说出“是什么、为什么重要、一个例子”时停止。记录耗时、实际打开页数、实际阅读页数、来源和自己的三句话；资料仍不够就记失败，不凑数。
2. 对同一个主题运行 B，另记从回车到三行出现的等待时间；三行出现后开始阅读计时，读完并确认看懂后停止。如果仍看不懂，记下来；若继续打开来源，也记录页数和额外时间。
3. 这是一次个人使用记录。由于先做传统查询会产生学习效应，不能用这一次的差值证明普遍提效；文章应同时披露顺序、熟悉程度、理解质量和样本量。不要挑最快的一次或把等待时间排除后宣传总节省。

```text
日期、设备：
主题、此前熟悉程度：
传统查询：____ 秒；实际打开 ____ 页，实际阅读 ____ 页
传统查询三句笔记/仍不清楚的点：
所用链接：
B 等待：____ 秒；阅读三行：____ 秒；追加查阅：____ 秒 / ____ 页
B 能否讲清三点、错误或遗漏：
测量顺序与外部帮助：
```

本表没有预填数字。收到真人原始记录后再写文章中的个人体验段；在此之前只能使用 [机器实测](lazy-payoff-measurement.md) 的有限结论。
